# Rémi Lamarche

  Fondateur de **[Waycraft.studio](https://waycraft.studio)**, un studio freelance basé à Toulouse. Je conçois
  des sites web, des applications et des automatisations pour les lieux culturels et d'hospitalité (bars,
  restaurants, galeries, hôtels-boutiques) et les PME multi-sites.

  Certifié **Product Builder** (Uncode School, 2026).

  ## Ce que je fais

  - **Construire** : sites vitrines, landing pages, applications web et mobiles.
  - **Connecter** : automatisations, agents IA et tableaux de bord qui font gagner du temps au quotidien.

  Je privilégie les outils open source (PocketBase, n8n) pour que les clients gardent la maîtrise de leurs
  données.

  - [Waycraft.studio](https://waycraft.studio/fr/etudes-de-cas) : le site du studio et son back-office.
